How it works

The demo calculates recommendations in your browser.

  • User-based: find users with similar rating patterns and aggregate their ratings.
  • Item-based: find movies co-rated by the same users and score candidates from the selected user's history.
  • Popularity: a non-personalized baseline using rating count and average rating.
This interactive browser demo is a lightweight implementation of collaborative filtering. It does not claim to run the trained Surprise SVD, NMF or TensorFlow models from the original notebook.

Dataset and privacy

The official MovieLens Small dataset contains 100,836 ratings, 610 users and 9,742 movies. Your selected CSV/ZIP is read locally by the browser; it is not uploaded to a server by this page.

Dataset: GroupLens MovieLens. Ratings are explicit 0.5–5 star ratings. This is an educational recommendation demo, not a production recommendation service.
