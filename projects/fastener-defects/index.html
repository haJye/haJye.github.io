About this demo

  • The model predicts one of six classes (nut / washer / screw × OK / NOK). The verdict adds up the probabilities of the three OK classes against the three NOK classes.
  • It was trained only on photos of nuts, washers and screws taken in one setup. Other parts, backgrounds or lighting will not be handled reliably, and any image gets some verdict. This is a portfolio demo, not a quality-control tool.
  • Accuracy figures come from a random 15% hold-out split. Photos of the same part may appear in both training and test data, so accuracy on truly new parts is likely lower.
  • Inference uses TensorFlow.js. The browser result matches the Python model (checked on the 18 sample images; differences below 2%, caused only by different JPEG decoders).
